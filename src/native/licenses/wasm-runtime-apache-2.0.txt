Libraries compiled into MediaPipe’s WebAssembly runtime (mediapipe/wasm/vision_wasm_internal.wasm), licensed under the Apache License 2.0 (its full text is listed separately). Google built the runtime from its own internal source tree, not from MediaPipe’s public build files (the runtime’s source paths say so). OpenCV’s version below is the one the runtime reports itself; the others are the versions MediaPipe’s public release v1.2.0 builds with, which may differ from those compiled in. Each library’s licence file at that version is the Apache License 2.0; TensorFlow’s adds the notice at the end.

The libraries are those the runtime’s own strings name (their source paths and messages). OpenCV’s version is from the runtime itself (the only library whose version it records). The others are from MediaPipe’s https://raw.githubusercontent.com/google-ai-edge/mediapipe/v1.2.0/WORKSPACE and https://raw.githubusercontent.com/google-ai-edge/mediapipe/v1.2.0/MODULE.bazel, and, for those TensorFlow brings in (ruy, gemmlowp, FlatBuffers, OR-Tools), from TensorFlow’s own build files at the commit above: MediaPipe’s public pins, which the internal build Google published may not have used. The runtime also contains Google code that has no public repository of its own (ML Drift, gloop), which comes with MediaPipe under its licence.
